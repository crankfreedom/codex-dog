# 验证策略与验收场景

> 原计划 0.4 的设计基线按职责迁入本文件；具体实现状态以 [G04 实施记录](g04.md) 为准。设计目录不等于已实现能力。

## 验证策略与最终验收

- 模块测试覆盖业务规则和公开契约，使用注入端口、假时钟与隔离目录，禁止测试真实认证文件和运行库。
- 集成测试覆盖事务、授权修订、目标锁、并发请求、数据分页及不同入口的一致性。
- 入口一致性验证使用相同初始夹具和授权上下文，比较结果、错误、状态迁移及副作用；不能对同一真实对象连续执行多次写操作来冒充等价验证。
- 依赖检查禁止桌面启动 CLI 完成业务调用、入口直连数据库或 Codex、业务内核依赖 CLI/MCP 实现；能力目录检查每项公开操作只有一个权威处理器。
- 文档、CLI 帮助、MCP Schema 与能力声明进行一致性检查；客户端预校验不能替代业务侧最终校验。
- 桌面与假 Codex 全流程验证额度耗尽、等待恢复、单次发送、回执、Goal、暂停、到期及重启。
- 协议测试检查 CLI/MCP 的 Schema、stdout、错误码、退出码、离线状态、版本兼容和权限拒绝。
- 更新测试使用实际安装的两个版本，覆盖后台检查、损坏包、断网、下载失败、安装前派发、退出超时、文件占用和迁移失败。
- 区分模拟、混合和真实证据；既有旧项目测试结果不能直接计入新项目验收。
- 真实读操作只取必要有界信息；真实发送和真实卡消费必须另有明确授权，不人为消耗额度制造测试条件。

最终验收清单：

- [ ] [4 设计基线](requirements.md)完整功能全部落地，桌面交互及公开接口均有覆盖。
- [ ] 模块边界与循环依赖检查通过，界面和 CLI 不直接访问数据库。
- [ ] 每项功能有“底层接口 → 统一业务能力 → CLI → 桌面/MCP”的交付证据，先验证一个完整功能再逐项扩展。
- [ ] 桌面、CLI、MCP 并列接入同一契约和唯一业务处理器；界面不启动 CLI，后台调度不复制状态迁移逻辑。
- [ ] 相同授权和初始状态下，各入口返回、错误及副作用一致，接口文档与能力声明一致。
- [ ] 安装后无需额外 Node.js，可按说明完成 CLI 和 MCP 接入。
- [ ] 应用驻托盘可调用，完全退出后不可调用，客户端不自动启动应用。
- [ ] 同一用户并发调用不造成重复任务、重复派发或重复卡消费。
- [ ] 明确展示数据来源、读取时间、过期和未知状态。
- [ ] 续跑授权、发送意图、回执和 Goal 完成语义保持一致。
- [ ] 全新数据目录与旧项目隔离，旧版并行托管冲突有有效防护。
- [ ] Windows 安装及在线升级实测通过，更新不重放未决操作。
- [ ] 接口、接入、权限、发布、故障恢复和开发文档齐备。

G03 仅对 A08/A16/A18 的持久化基础及旧锁协议提供模拟技术证据，完整任务授权、真实派发、卡预约和全部验收仍未完成，详见 [G03](g03.md)。

G04 对额度/会话/无当前 Goal 提供真实只读证据，对 Schema/账号切换/Goal 六种状态和冲突等提供独立夹具证据；不表示 A10–A18 的全功能或真实副作用全部验收，见 [G04](g04.md)。

## 可执行验收场景目录

以下为未来需要实现和执行的验收，不是本次已通过的测试。每个场景留存输入夹具、调用入口、返回/退出码、持久状态及外部调用次数；真实副作用必须另获授权。阶段 0 只核对场景与契约覆盖关系。

| 编号 | 场景与输入 | 必须观察到的结果 | 验证方式与阶段 |
|---|---|---|---|
| A01 | 导入/构造全部模块 | 无文件读写、连接、进程启动或计时器；显式 start 后才动作 | 注入记录端口，阶段 2 |
| A02 | 扫描模块与入口依赖 | 无循环、无内部跨模块引用、无 UI 启动 CLI、无 CLI/MCP 直读源库；唯一处理器归属明确 | 导入边界及能力目录检查，阶段 2 起 |
| A03 | 应用未启动时执行 quota get | APP_NOT_RUNNING、退出码 5；不拉起主应用或创建运行库 | 安装版 CLI，阶段 1 |
| A04 | 应用驻托盘、业务进程启动中或崩溃恢复中 | 驻托盘可读；未就绪返回 APP_NOT_READY；不伪造空任务或额度 | 最小宿主及进程夹具，阶段 1–2 |
| A05 | 相同夹具/授权经 CLI、IPC、MCP 调用同一操作 | 结果、错误、状态及副作用计数一致；传输元信息可不同 | 重置隔离夹具分别调用，阶段 1 起 |
| A06 | 中文/空格路径、stdin JSON、重复字段、超限输入 | 有效输入无损；非法字段和重复来源拒绝，stdout JSON 可解析且 stderr 不污染结果 | CLI 协议验证，阶段 1 |
| A07 | 客户端自报 scopes、未配对、自授权限或使用已撤销凭据 | 拒绝；正文默认脱敏；有权限也不能读取聊天/认证文件 | 授权及 ACL 验证，阶段 1–2 |
| A08 | 同键同参数、同键不同参数及客户端超时重连 | 同参数返回原操作，不重复副作用；不同参数冲突；超时通过原操作核对 | 并发与崩溃夹具，阶段 2–4 |
| A09 | 设置/任务读取后另一客户端修改再保存 | expectedRevision 冲突，未覆盖新值；暂停标志不被异步保存覆盖 | 并发夹具，阶段 3–4 |
| A10 | 多个实例、读取身份变化、缺失必要工具 Schema | 不猜选、不继承旧身份授权；对应能力标未知或不支持 | 接入夹具及授权只读对照，阶段 1–3 |
| A11 | 缺额度窗口、已过预计恢复时间、额度读取失败 | 未知或不可用；不按预计时间发送；实时恢复证据齐全才允许后续评估 | 额度夹具，阶段 3–4 |
| A12 | quota.refresh/diagnostics.run 与 scheduler.runNow 对照 | 前者不改计划、授权、计数或调度缓存；后者明确可能推进已授权续跑 | 调用记录与状态快照，阶段 3–4 |
| A13 | Goal 缺库、未知状态、无行、前后身份变化 | 未知保守停止；确认无行仍结合轮次；前后变化冲突，不读 objective | 只读临时 SQLite，阶段 3 |
| A14 | 最新轮次正常完成、旧额度错误、审批、主动中断或普通错误 | 不误触发额度续跑；未结束 Goal 的正常单轮完成继续观察 | 状态机夹具，阶段 4 |
| A15 | 自动任务无具体授权、超次数、改 Goal、改连接身份 | 禁止投递；创建与开启同样检查，计数不因暂停编辑重置 | 授权夹具，阶段 4 |
| A16 | 投递准备提交前后故障、并发争槽 | TX02 全部回滚或完整保存；同目标至多一个持有者；不产生无意图网络写入 | 事务故障注入，阶段 4 |
| A17 | 派发重连期间暂停/撤销/换账号，在 socket 写入前再次变化 | finalGuard 阻断；确定未写入可取消；实际已写入不能返回未发送 | 传输边界夹具，阶段 4 |
| A18 | 网络写入后断连、响应丢失、sending 期间崩溃 | intent、held、原 marker 保留，进入 uncertain；重启、超时和重连均不重发 | 发送计数及持久库夹具，阶段 4 |
| A19 | 已提交、唯一回执匹配、对应轮次结束、Goal 最终完成 | 四个事实分别记录；槽位只在对应终态释放；不提前标整个任务完成 | 回执与 Goal 多轮夹具，阶段 4 |
| A20 | 未决期间编辑、移除、换模式或重建同目标任务 | 全部阻断绕行，核对仍可执行，不重置计数/槽位 | 多入口状态验证，阶段 4 |
| A21 | 队列降上限、高优先级到达、同级移动、仅观察 | 不抢占已提交轮次；顺序稳定；仅观察不产生意图、不计数或占槽 | 队列夹具，阶段 4 |
| A22 | 跨午夜时段、起止边界、到期、时区变化和休眠恢复 | 明确本机时区语义；开始含结束不含；到期停投递而非完成，恢复重新核验 | 假时钟及本机时区夹具，阶段 4 |
| A23 | threads.send 指向受托管、审批中、运行中或有 Goal 的目标 | 拒绝；合格空闲目标才创建单次 attempt，不能绕过托管暂停或队列 | 显式发送夹具，阶段 4 |
| A24 | 旧 CLI 与新应用同时争同一目标，旧锁路径自定义或持有者未知 | 原子互斥；不清理活锁；无法确认兼容则 TARGET_LOCK_UNVERIFIED，真实发送零次 | 隔离锁协议竞争，阶段 1，真实投递前门禁 |
| A25 | 多次预约同卡、并发到期领取、消费前账号/卡变化 | 唯一活动约束及原子领取生效；复核失败不消费别卡 | 卡片及事务夹具，阶段 5 |
| A26 | 消费响应丢失后核对 | 原卡原键，明确是否可能完成原消费；不换键、不建新预约绕过 uncertain | 幂等服务夹具，阶段 5 |
| A27 | 退出/休眠错过预约、取消已领取预约 | 标 missed 且不补用；已领取不冒充成功取消；状态与消费次数可审计 | 假时钟与退出夹具，阶段 5 |
| A28 | 模板更新/复制、任务暂停编辑、设置分区同时保存 | 模板不追改任务；修订保持暂停；监控与外观不互相覆盖 | 模板、修订和设置夹具，阶段 3–4 |
| A29 | 翻页期间新事件写入或日志聚合、取消范围导出 | 游标不重复/跳变；导出固定快照；取消不留下成功文件，超范围路径拒绝 | 大量临时事件及导出夹具，阶段 3 |
| A30 | 未知数据库高版本、迁移失败、带 WAL 的备份恢复 | 高版本拒绝；失败事务回滚；备份恢复一致；旧库完全未读写 | 隔离数据目录，阶段 2、6 |
| A31 | 新旧 CLI/API major 不兼容及长操作断连 | 不兼容拒绝；已接受操作保留 operationId；退出命令不以断连表示成功 | 安装版及进程夹具，阶段 1、6 |
