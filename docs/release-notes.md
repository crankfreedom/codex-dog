# 0.6.0-beta.8 Preview 候选说明

## 可用功能

- 新增任务与提示词模板：默认暂停/仅观察、修订授权、次数/有效期/跨午夜时段、优先级、同级顺序和并发槽位。
- 单次显式发送与托管共用意图、目标互斥、持久幂等及结果核对；未决保留，不通过编辑、重建或重启补发。
- 新增指定重置卡预约、取消、原子领取及原卡原键核对；错过不补用，同账号未决阻断其他卡。
- 新增归档/时间线、任务诊断、脱敏通知、有界历史订阅和安装更新页面；桌面/CLI/MCP 共用唯一处理器。
- 当前 83 项能力、API 3 / Schema 11；已有授权不扩权。正式图标、接入文档和备份恢复说明已接入。

## 安装与使用

1. 从 [阶段 6 清单](stage6.md) 核对本机候选的版本、路径、字节数及 SHA-512，再启动 Preview NSIS 安装器。当前未签名，Windows 可显示未知发布者或 SmartScreen 提示。
2. 打开 CodexDogPreview.exe；默认使用独立模拟 profile，可审阅任务、卡片、投递、设置及历史页面。
3. 配套 resources/cli/codex-dog.exe 内置运行时。保持主应用运行，按 [接入手册](cli.md) 分别配对 CLI/MCP 并批准必要权限。
4. 关闭窗口继续驻托盘；托盘明确退出后 CLI/MCP 返回离线，不会拉起主应用。
5. 已有本应用数据可升级；未决仍须原记录核对。卸载不删除 profile，恢复操作见 [恢复手册](recovery.md)。不导入旧产品数据。
